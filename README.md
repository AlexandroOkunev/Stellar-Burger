# Stellar Burger 🍔

Интерактивное веб-приложение «космической бургерной» с возможностью сборки конструктора, авторизацией через JWT и отслеживанием ленты заказов в реальном времени.

- **Основное демо (GitHub Pages):** [https://alexandrookunev.github.io/Stellar-Burger/](https://alexandrookunev.github.io/Stellar-Burger/)  
  *(✅ Гарантированно работает в РФ без VPN)*
- **Зеркало (Vercel):** [https://stellar-burger-izfj8st3v-alexxandr-and-ko.vercel.app](https://stellar-burger-izfj8st3v-alexxandr-and-ko.vercel.app)

## 🛠 Стек технологий

- **Core:** React, TypeScript, Redux Toolkit
- **Routing:** React Router (HashRouter для совместимости со статическим хостингом)
- **Real-time:** WebSocket
- **Сборка:** Webpack, SCSS, Babel
- **CI/CD & Деплой:** GitHub Actions, GitHub Pages, Vercel

## ✨ Ключевые особенности реализации

1. **Отказоустойчивость (Mock Layer):**  
   Так как учебный API Яндекс Практикума (`norma.nomoreparties.space`) часто бывает недоступен, в проект внедрён типизированный слой мок-данных. При падении сетевого запроса приложение автоматически подхватывает локальные данные, гарантируя, что рекрутер или техлид всегда увидят полностью рабочий интерфейс, а не ошибку сети.
2. **Автоматизация (CI/CD):**  
   Настроен пайплайн через GitHub Actions (`.github/workflows/deploy-pages.yml`), который автоматически собирает проект и деплоит его на GitHub Pages при каждом push в ветку `main`.
3. **Корректный SPA-роутинг:**  
   - Для Vercel сконфигурирован `vercel.json` с правилами `rewrites`, чтобы избежать ошибок 404 при обновлении страницы на вложенных роутах.
   - Для GitHub Pages использован `HashRouter`, что является наиболее надёжным решением для статических хостингов без серверной конфигурации.
4. **Оптимизация ассетов:**  
   В `webpack.config.js` настроен `publicPath: './'`, что гарантирует корректную загрузку шрифтов, изображений и бандлов независимо от уровня вложенности URL.

## 📦 Функционал

- Drag-and-drop конструктор бургера (добавление/удаление ингредиентов).
- Модальные окна с деталями ингредиентов и заказов (с сохранением background-локации).
- Регистрация, авторизация и обновление токенов (JWT).
- Защищённые роуты (редирект неавторизованных пользователей из профиля и наоборот).
- Лента всех заказов и страница профиля с историей заказов пользователя.
- Валидация форм и обработка состояний загрузки/ошибок.

## ⚙️ Запуск проекта локально

**1. Клонируйте репозиторий:**

    git clone https://github.com/AlexandroOkunev/Stellar-Burger.git
    cd Stellar-Burger

**2. Установите зависимости:**

    npm install

**3. Настройте переменные окружения** — создайте файл `.env` в корне проекта:

    BURGER_API_URL=https://norma.nomoreparties.space/api

**4. Запустите в режиме разработки:**

    npm run start

Приложение будет доступно по адресу: `http://localhost:4000`

**5. Для продакшен-сборки:**

    npm run build
